# src
Main source code.

| Module | Purpose |
|---|---|
| `core/` | Config loading, logging, shared types |
| `llm/` | LLM clients / providers, prompt rendering |
| `rag/` | Ingestion, chunking, embeddings, vector store, retrieval |
| `agents/` | Agents, tools, orchestration |
| `ml/` | Classical ML / DL: features, training, inference |
| `security/` | Detection, scanning, guardrails, threat analysis |
| `api/` | Backend API (e.g. FastAPI) |
| `utils/` | Generic helpers |
